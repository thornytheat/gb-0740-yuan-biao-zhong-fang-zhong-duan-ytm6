# 数据字典

| 字段 | 含义 | 约束 |
|---|---|---|
| `switch.live`, `switch.through` | 编码上线日与数据截止日 | `YYYY-MM-DD`，截止日不晚于上线日。 |
| `sources[].id` | 来源标识 | ASCII 字母、数字、下划线和短横；每来源至多 40 个声明旧键。 |
| `sources[].consumers`, `upgraded` | 消费者总数与已升级数 | 0–999 整数，已升级不超过总数。 |
| `sources[].old_rows`, `new_rows` | 旧键在途与新键到达行数 | 非负整数，兼容全角千分位；新键低于旧键即未全覆盖。 |
| `sources[].old_keys[]` | 来源声明的旧键键空间 | 去重；映射只接受已声明旧键。 |
| `mappings[].source`, `old`, `new` | 旧键到新键的映射证据 | 来源与旧键须已登记；多旧键共用一新键判证据不全。兼容旧 `count` 字段。 |
| `mappings[].rows`, `checked` | 证据行数与核对标记 | 未核对的映射判证据不全。 |
| `comparisons[].snapshot`, `checksum`, `keep_until`, `retained` | 旧键对照快照、校验锚、保留期与留存标记 | 每来源至多一条；保留期须不早于上线日，丢失即已切换区域无法复核。 |
| `deliveries[].day`, `key`, `version`, `anchor` | 已交付分区、键制、版本与回退锚点 | 分区由 `source@YYYY-MM-DD` 标识；`key` 为 `old` 或 `new`；新键交付须带锚点才能回退到原区域，缺锚判断链。交付日不晚于数据截止。 |

相同记录重传计为重复。同键候选打架时整组隔离，保留源行号。隔离行不参与判定，但映射冲突会使该来源证据判不全。

准入状态按来源三态：独立交付、旧键对照、不可放行。发布、回查、补数三务从同一份准入派生，每行带回准入编号。回退演练把新键交付恢复为锚点旧键版本，核对断链、残留与影响外变动，回退幂等。

受影响行数使用整数，超出 JSON 常见安全整数范围的汇总按字符串输出。准入批次绑定原始字节和规则版本，文件大小至多 300 KiB。
